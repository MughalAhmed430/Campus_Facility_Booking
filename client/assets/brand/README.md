# University logo

Copy the official Kyungdong University logo here as `kdu-logo.png` (a PNG about 72 px
high, transparent background). The header then shows it instead of the project's own
calendar mark, and the footer adds "Logo and images used with permission of Kyungdong
University". Without the file, nothing changes. The logo is not committed to the
repository: use it only with the university's permission.
